# Legacy Test `com` Package Chain

## Overview
Package chain (`com`) of the legacy test source root; only `ivy` is present below it.

## Subdirectories & Boundaries
- [ivy](./ivy/EGM.md) - Top-level test package of `:temp:legacy-code`; only `legacy` is present.

## Invariants
- Identical in shape to the main source chain, which is why a `com/ivy/...` path alone does not tell you whether a file is production or test.

## Side Effects
- None.
