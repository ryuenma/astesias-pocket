# com.ivy.planned

## Overview
Package root of `:feature:planned-payments`. It declares no symbols itself; it groups the two independent
sub-packages that make up the feature, each with its own navigation screen and ViewModel.

## Subdirectories & Boundaries
- [edit](./edit/EGM.md) - Create/edit a planned-payment rule plus bill reminders.
- [list](./list/EGM.md) - Planned-payments list, pending bills and cards.
