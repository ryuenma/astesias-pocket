# com.ivy.loans

## Overview
Package root of `:feature:loans`. It declares no symbols itself; it groups the two independent
sub-packages that make up the feature, each with its own navigation screen and ViewModel.

## Subdirectories & Boundaries
- [loan](./loan/EGM.md) - Loans list tab with pending/completed lists.
- [loandetails](./loandetails/EGM.md) - Single-loan details, records and modals.
