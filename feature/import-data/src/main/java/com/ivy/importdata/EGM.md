# com.ivy.importdata

## Overview
Package root of `:feature:import-data`. It declares no symbols itself; it groups the two independent
sub-packages that make up the feature, each with its own navigation screen and ViewModel.

## Subdirectories & Boundaries
- [csv](./csv/EGM.md) - CSV column-mapping screen and its parsing domain.
- [csvimport](./csvimport/EGM.md) - Guided import flow (steps, UI, instructions).
